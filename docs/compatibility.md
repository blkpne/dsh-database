### 取消与部署范围

- PostgreSQL、MongoDB 已覆盖服务端在途操作终止与恢复。
- SQL Server、Oracle 的记录覆盖客户端取消，不包含一般性的服务端在途终止验收。
- 客户端取消、关闭连接与服务器停止计算是不同结果。具体实现和清理证据见[超时与取消](reference.md#超时与取消)。
- 本页验证范围不包含集群、故障转移和 MongoDB Atlas/SRV；表单支持 SRV 不代表相应部署方式经过验证。
